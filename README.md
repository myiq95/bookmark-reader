# 책갈피 — 개인 독서 웹앱

## GitHub Pages 설치
1. 이 폴더의 파일을 GitHub 저장소 루트에 업로드합니다.
2. 저장소 Settings → Pages → Deploy from a branch → `main` / `/(root)`를 선택합니다.
3. 배포된 HTTPS 주소를 iPhone Safari로 엽니다.
4. 공유 버튼 → 홈 화면에 추가를 누릅니다.

## 주요 기능
- 서재 등록 및 IndexedDB 저장, 읽는 중/완독 탭
- 읽던 위치 자동 저장 및 이어 읽기
- TXT, MD, HTML 기본 읽기 / DOCX, PDF, EPUB 변환 지원
- 한글 TXT UTF-8 우선, 실패 시 EUC-KR(CP949 호환 계열) 시도
- 제목/장/화/부/편 등의 자동 목차 인식, 직접 목차 입력
- 시스템 음성 합성(SpeechSynthesis), 글자 크기·글꼴·나이트 모드
- 기본 셸 오프라인 캐시

## 현재 구현의 제한
- PDF/DOCX/EPUB 변환 라이브러리는 첫 사용 시 CDN에서 받아옵니다. 따라서 해당 형식의 **최초 변환은 인터넷 연결이 필요**하며, 라이브러리 자체가 오프라인 캐시되어 있지 않습니다.
- PDF는 텍스트 레이어가 있는 문서만 읽습니다. 스캔 이미지 PDF의 OCR은 포함하지 않았습니다.
- 브라우저의 TextDecoder는 CP949/ANSI를 모든 환경에서 지원하지 않습니다. UTF-8 및 EUC-KR 계열을 시도하지만, CP949 전용 문서의 완전한 호환을 보장하지 않습니다.
- 자동 목차는 문서 제목 패턴을 추정합니다. 직접 목차를 지정하면 각 항목의 본문 일치 위치를 연결합니다.
- 시스템 TTS 음성·한국어 음성 제공 여부는 iPhone 설정과 브라우저에 따라 달라집니다.
- iOS Safari의 저장공간 정리나 앱 제거 시 로컬 서재 데이터가 삭제될 수 있습니다. 현재 백업/복원 기능은 없습니다.
